Searching                                              *my_commands_searching*

:Rg - Searches for text using ripgrep from the current work directory
:Crg - Searches for text from the current buffer's directory
:Prg - Searches for text from the top-level project
:Rrg - Searches for text from the top-level repository

Terminals                                              *my_commands_terminals*

Create 2+ Terminals                    *my_commands_create_multiple_terminals*

:1ToggleTerm, :2ToggleTerm, etc creates multiple terminal windows
